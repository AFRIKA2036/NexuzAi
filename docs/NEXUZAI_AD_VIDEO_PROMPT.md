# NexuzAI — Ad Video Generation Prompt

Use this prompt when generating marketing/ad videos for NexuzAI in AI video tools (Runway, Pika, Sora, Kling, etc.).

---

You are creating a high-energy product ad for NexuzAI.

Brand identity
- Name: NexuzAI
- Tagline: Your AI Agent Hub
- Core visual: dark purple and white color scheme, centered white hexagon logo mark with small center dot
- Voice: professional, confident, empowering

Product
- NexuzAI is an AI agent hub with a curated suite of intelligent agents.
- Key agent use cases to feature: resume writing, cover letters, email drafting, study notes, contract analysis, LinkedIn optimization, research reports, code mentoring, viral content creation, meeting minutes, startup planning, academic essays, code conversion, trip planning, event planning.

Target audiences
- Job seekers
- Software developers
- Busy professionals
- Students
- Entrepreneurs and founders

Story beats (short-form)
1) Hook: Show someone stuck or overwhelmed by a task.
2) Reveal: NexuzAI agent solves it in one step.
3) Proof: Quick montage of use cases.
4) CTA: Try NexuzAI today.

Visual style
- Sleek, modern product visuals
- Dark purple background with bright white accents
- Hexagon motif as transition/logo overlay
- Clean UI mockups of agents in action
- Dynamic text overlays listing use cases

Audio/music
- Upbeat, modern corporate-ambient track
- Premium feel; no cheesy tech stings

Output specs
- 16:9 primary, 9:16 secondary cut
- 15–60 seconds
- No tool watermarks
- Final frame must include the NexuzAI logo mark

Brand safety
- Do not show personal data or sensitive documents
- Do not promise guaranteed outcomes
